# Mashed Potato

Personal portfolio site for Ishita Acharya.

## What’s inside

- `index.html` - the full portfolio page, styles, and client-side behavior
- `assets/` - resume and supporting static files
- `netlify.toml` - Netlify publish configuration

## Run locally

This is a static site, so you can open `index.html` directly in a browser or serve the folder with any simple static server.

## Update the website

1. Edit the files in VS Code.
2. Save your changes.
3. Commit and push to GitHub.

Netlify is linked to this repository, so every push to `main` triggers an automatic redeploy.
